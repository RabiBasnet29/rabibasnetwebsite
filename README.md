# Rabi Basnet Portfolio

Animated single-page portfolio inspired by the uploaded reference video.

## Features
- Animated geometric hero artwork and portrait composition
- Canvas network background
- Floating glass cards and orbit graphics
- Scrolling technology marquee
- Interactive bento expertise grid with tilt effects
- Animated experience timeline
- Radar contact graphic
- Scroll reveal, counters, progress indicator and reduced-motion support
- Responsive layout for desktop, tablet and mobile

Open `index.html` directly, or deploy the folder to GitHub Pages, Netlify, Vercel or any static web host.
